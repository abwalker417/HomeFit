HomeFit ↔ Apple Health Shortcuts

Two shortcuts keep all three apps in sync — HomeFit, Sparky, and Apple Health — with no duplicate workouts. This guide walks through building both, step by step.

ActivityHomeFitSparkyApple Health
Gym session (HomeFit) ✓ native ✓ auto-sync (built in) ✓ Shortcut 1 (below)
Walk / run / cardio (Watch, Oura) ✓ Shortcut 2 (below) ✓ Shortcut 2 forwards it ✓ native
How duplicates are prevented Shortcut 2 sends every finished workout to HomeFit, and the HomeFit server decides what to do. If the workout overlaps a session already logged in HomeFit (within 20 minutes), it is skipped — because that session already synced to Sparky with full details. Only genuinely external activity (walks, runs, rides) gets forwarded to Sparky. You never have to filter anything by hand.

Before you start: get your token

  1. Open HomeFit and go to Profile (hamburger menu → Profile).
  2. Scroll to the Integrations section.
  3. You'll see a URL like:
    http://192.168.68.15:5000/api/last_workout?token=AbC123...
  4. The long string after token= is your personal API token. You'll paste it into both shortcuts below. Keep it private — it identifies you to HomeFit.
Use the public address in shortcuts Walks happen away from home, so always use https://homefit.hidethechaos.com in the shortcuts — not the 192.168.x.x address. The Cloudflare address works from anywhere.

Shortcut 1 — Gym credit in Apple Health

Pulls your latest HomeFit workout and logs it into Apple Health so you get ring credit. Runs automatically every evening; it only logs if you actually trained that day.

1Create the shortcut

  1. Open the Shortcuts app → Shortcuts tab → + (top right).
  2. Rename it (tap the title at the top): HomeFit to Health.
  3. Add the actions below, in order. Use the search bar at the bottom to find each action by name.

Tips while building:

  • For the If action: tap the input field → select the Dictionary Value variable → condition contains → tap the text field → insert the Current Date variable → tap the inserted variable → set Date Format: Custom → yyyy-MM-dd. This makes the shortcut do nothing on rest days (so it never double-logs an old workout).
  • In Log Workout, the start/end/calories values come from the URL response: tap each field → Select Variable → choose Contents of URL → set Get Value for Key to start_time, end_time, or kcal.
  • The first run will ask for Health permission — allow write access to Workouts.

2Automate it

  1. Shortcuts app → Automation tab → +.
  2. Choose Time of Day → set 9:00 PM, repeat Daily.
  3. Select Run Immediately (so it doesn't ask each night).
  4. Pick the HomeFit to Health shortcut → Done.

Why 9 PM? By then the day's workout is finished and logged in HomeFit. If you trained, it lands in Apple Health that evening; if you rested, the date check fails quietly and nothing happens. You can also run the shortcut manually right after a workout if you want instant ring credit.

Shortcut 2 — Cardio into HomeFit & Sparky

Fires automatically whenever a workout ends on your Watch (or lands in Apple Health from Oura). Sends it to HomeFit, which skips anything that overlaps a HomeFit session and forwards the rest to Sparky.

1Create the shortcut

  1. Shortcuts app → Shortcuts tab → + → rename to Health to HomeFit.
  2. Add these two actions:
Health to HomeFit

URLGet Contents of URL

MethodPOST
BodyJSON
typeWorkout Type
startStart Date (ISO 8601)
endEnd Date (ISO 8601)
kcalActive Energy (number)
distance_miDistance (number)

Tips while building:

  • In Get Contents of URL, tap Show More to reveal Method and Request Body. Set Method to POST and Request Body to JSON.
  • Add each JSON field with Add new field → Text (for type and the dates) or → Number (for kcal and distance_mi).
  • For each value, tap the field → Select Variable → pick Workouts (the Find Workouts result) → choose the property (Workout Type, Start Date, End Date, Active Energy, Distance).
  • For Start Date and End Date: after inserting the variable, tap it and set Date Format: ISO 8601, and turn on ISO 8601 Time.
  • The first run asks for Health permission — allow read access to Workouts.

2Automate it

  1. Shortcuts app → Automation tab → +.
  2. Choose Workout (Apple Watch) → Ends → any workout type.
  3. Select Run Immediately.
  4. Pick the Health to HomeFit shortcut → Done.

Oura workouts The Watch automation only fires for Apple Watch workouts. Oura writes its workouts into Apple Health, but that won't trigger the automation. To catch those, add a second automation: Time of Day → 10:00 PM Daily → Run Immediately → Health to HomeFit. Bump the Find Workouts limit from 1 to 3 if you want the nightly sweep to catch multiple activities — the server ignores anything it has already received, so re-sending is always safe.

Test it

  1. Open Health to HomeFit in the Shortcuts app and tap Run (the play button).
  2. It grabs your most recent workout and posts it. Add a Quick Look action at the end temporarily to see the server's reply:
  • ✓ {"status": "synced", ...} — forwarded to Sparky. Check Sparky's exercise diary.
  • ✓ {"status": "skipped", "reason": "overlaps HomeFit workout..."} — correctly recognized as a HomeFit session. No duplicate created.
  • ✓ {"status": "duplicate"} — this exact workout was already received. Safe to ignore.
  • {"error": "invalid token"} — re-check the token in the URL.

Troubleshooting

SymptomFix
invalid token (401) The token= value doesn't match. Copy it again from Profile → Integrations. No spaces or line breaks.
unparseable start (400) The date variable isn't formatted as ISO 8601. Tap the Start/End Date variable in the shortcut and set Date Format to ISO 8601 with time enabled.
Walk shows in HomeFit but not Sparky Response said "status": "recorded" — Sparky sync is off or the Sparky API key is missing. Check Profile → Integrations → Sparky in HomeFit.
Gym session duplicated in Sparky Shouldn't happen — the server skips overlaps within 20 minutes. If the watch workout and the HomeFit log are more than 20 minutes apart, the window missed it; mention it to Claude to widen the window.
Automation never fires Make sure "Run Immediately" is selected and notifications for Shortcuts are allowed. Watch automations need the iPhone nearby/online.
Two walks same day merged in Sparky Known Sparky limitation: it dedups manual entries by exercise + date, so a second walk on the same day updates the first entry's stats instead of adding a new row. HomeFit still records both.
